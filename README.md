This public repository contains released datasets, lab notebooks, and problem-set
templates for GB656. Solutions and instructor materials are not included.

Students do not need to clone this repository or use Git. Open the notebooks through
the Google Colab links below; the notebooks load their course data automatically.

## Complete and submit Problem Set 1

1. Open the problem-set template using the Colab link above.
2. Before editing, select **File > Save a copy in Drive**.
3. Work only in the saved copy and rename it so the filename includes `PS1` and your
   name.
4. Complete every code and written-response task.
5. Select **Runtime > Run all**. Confirm that every requested output is visible and
   no cell reports an error, then save the notebook.
6. Click **Share**. Under **General access**, choose **Anyone with the link**, set the
   role to **Viewer**, and copy the sharing link.
7. Submit the link to the completed Drive copy as the **Website URL** in Canvas. Do
   not submit the original GitHub template link.
8. After the deadline, do not edit the submitted notebook unless the instructor asks
   you to resubmit.

## Data

The notebooks use the course copy of `data/car_price_prediction.csv`. Its source,
provenance, checksum, and upstream licensing declaration are documented in
[`data/README.md`](data/README.md).

## Troubleshooting

- If your changes disappear, confirm that you selected **File > Save a copy in
  Drive** and are editing that copy.
- If the data-loading cell fails, rerun the instructor-provided setup and loading
  cells without editing the repository name or filename, and confirm that the Colab
  runtime has internet access.
- Before submitting, open the sharing link in a private/incognito browser window. It
  should display the completed notebook without requesting access.

No repository-wide license for the instructor-authored course materials has been
selected yet. Dataset terms and attribution are recorded separately in the data
documentation.
